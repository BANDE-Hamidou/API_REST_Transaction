\section{Le test de bout en bout}
L'énoncé exige un test de bout en bout de la chaîne principale. \nolinkurl{tests/e2e/chaine-complete.test.js}
enchaîne sept vérifications ; le numéro de celle qui échoue désigne le maillon en défaut :
\begin{enumerate}
  \item l'API et la base répondent ;
  \item les données chargées sont cohérentes avec le fichier produit (et avec le résultat attendu si elles viennent de KNIME) ;
  \item les filtres et la pagination renvoient des résultats corrects ;
  \item un cycle complet création, lecture, modification, suppression, avec les erreurs attendues ;
  \item \texttt{/metrics} expose requêtes, erreurs et temps de réponse ;
  \item Prometheus collecte les métriques de l'API ;
  \item Grafana est provisionné (source Prometheus et tableau de bord).
\end{enumerate}
